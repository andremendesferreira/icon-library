Licenses and attribution

Last updated: November 9, 2026

Every icon on Icon Library is open source and can be used in personal and commercial projects. Each set keeps the license of its own authors. This page sums them up, so you know what to keep when you use them.

Using an icon in your project

You can use the icons in websites, apps, documents and products, commercial or not, and change them as you like, in the editor or elsewhere. ISC and MIT ask for one thing: where the icons themselves are copied or redistributed — inside a package, a library or a project's source code — keep the copyright notice and the license text. A LICENSE or THIRD-PARTY-NOTICES file that lists each set is the usual way. These licenses do not require a visible credit on the page, but one is always welcome.

Edited and combined icons

An icon changed in the editor keeps the license of the set it came from. If you put icons from two sets together, keep both notices.

Brand logos

Some sets include logos of companies and products — Bootstrap Icons, for example. The icon license covers the drawing, not the brand: using a trademark follows its owner's rules. That is also why Iconlibrary does not accept logos.

Emoji

Emoji are Unicode characters. Copying one copies the character, and each device draws it with its own font — from Apple, Google, Microsoft and others, each under its own terms. The SVG of an emoji only wraps the character, so it still depends on that font.

Icon Library itself

The site's code is open source under the MIT license, on GitHub.

This page is a summary to help you, not legal advice: the license texts linked above are what count.
