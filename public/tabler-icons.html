Tabler Icons

Tabler Icons is an open-source set of nearly 5,500 outline icons, made by Paweł Kuna as part of the Tabler project. It is one of the largest free sets with a single consistent style, and about a thousand of its icons also come in a filled version.

What the style gives you

The icons are drawn on a 24×24 grid with a 2-unit stroke, rounded ends and no fill, the same rules as Lucide and Feather. That makes the three easy to mix: a Tabler icon next to a Lucide one has the same weight and the same corners. Because the shapes are lines, stroke-width makes an icon lighter or heavier without a second file, and currentColor lets it follow the color of the text.

The size of the set is the main reason to choose it. Tabler covers areas that smaller sets skip: many variations of the same object (battery, battery-1 to battery-4, battery-charging), “off” versions for disabled states, and whole families for charts, devices, currencies, weather and sports.

Outline and filled

Around a thousand icons have a filled twin. Use the filled one to show a state that is on: a selected star, a liked heart, an active tab. In Icon Library the filled versions end in filled, and the Outline and Filled buttons show only one kind. Mixing the two kinds as plain decoration in the same row looks uneven, because a filled shape weighs more.

License

Tabler Icons uses the MIT license: you can use the icons in personal and commercial projects and modify them. Keep the license notice when you redistribute the package itself. The set includes some company and product logos (the brand- icons); the license covers the drawing, not the brand, so a logo follows its owner’s rules.

Using it in a project

For one or two icons, pasting the SVG is enough and adds no dependency:

<button aria-label="Settings">
      <svg aria-hidden="true" viewBox="0 0 24 24" width="24" height="24" fill="none"
           stroke="currentColor" stroke-width="2">…</svg>
    </button>

In React, the official package exports each icon as a component whose name starts with Icon:

npm install @tabler/icons-react

    import { IconSettings } from "@tabler/icons-react";

    <IconSettings size={20} stroke={1.5} />

Note that the stroke property is called stroke, not strokeWidth as in Lucide. There are packages for Vue, Svelte, Solid and Preact too, and a webfont; see tabler.io/icons for the current list.

Tabler or Lucide?

Both follow the same grid and stroke, so the choice is about coverage and habit. Lucide has fewer icons, chosen with care, and its names follow Feather’s. Tabler has almost three times as many and the filled versions, so it is more likely to have a specific object or a state. Many projects use Lucide as the base and take the few missing icons from Tabler, which works because the styles match.

Common mistakes

  • Importing the whole set. With thousands of icons, an import of everything makes the bundle heavy. Import each icon by name, as above, so the build keeps only what you use.
  • A button with only an icon and no name. A screen reader has nothing to announce. Put aria-label on the button and aria-hidden="true" on the SVG.
  • Mixing outline and filled without a reason. Keep filled for an active or selected state, and outline for everything else.

To change a Tabler icon, or combine it with an icon from another set, open it with the pencil in the online SVG editor.
