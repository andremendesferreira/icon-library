Icon Library について

Icon Library は、メニューやボタン、UI に使うアイコンを選ぶための無料ツールです。人気の 4 つのセットを検索できる 1 つのページにまとめているので、スタイルを並べて比べ、必要なものをそのままコピーできます——HTML に貼れる SVG、React コンポーネント、PNG、絵文字。

アイコンセット

Lucide
24×24 のグリッドに 2px の線で描かれた、すっきりした線画アイコン約 1,900 個。コミュニティが管理する Feather のフォークで、現在もっとも充実した線画セットです。ライセンス：ISC。
Feather
約 290 個のアイコンからなる、元祖ミニマルな線画セット。Lucide はここから生まれたため、スタイルも多くの名前も共通しています。ライセンス：MIT。
Bootstrap Icons
Bootstrap チームによる 2,000 個以上のアイコン。多くは線画版と塗りつぶし版（名前に -fill）があります。16×16 のグリッドに塗りつぶしの図形で描かれています。ライセンス：MIT。
Emoji (Unicode)
標準の絵文字すべてを、Unicode 規格のとおりにグループ分けしています。ほかのセットと違って絵文字は文字なので、見た目は各端末にインストールされたフォントによって変わります。

検索、スタイル、Scratchpad、アイコンエディター、.ile プロジェクト、キーボードショートカットなど、各機能のステップごとの説明はガイドにあります。

よくある質問

一部の絵文字に「デザインなし」と表示されるのはなぜですか？

最新の絵文字は、OS がそれを描画できるフォントを提供する前に Unicode 規格に追加されます。このページはシステムフォントが各絵文字を描画できるかを確認し、できないものに印を付けます。メニューでは使わないでください：訪問者には空の四角が表示される可能性が高いです。この端末で表示できるものだけにチェックを入れると非表示になります。

UI には絵文字とベクターアイコンのどちらを使うべきですか？

ベクターアイコンはどこでも同じ見た目で、文字色を引き継ぎ、きれいに拡大縮小できます。絵文字は手軽に追加できますが、Windows、macOS、Android、iOS で見た目が変わります。製品の UI には、たいていベクターアイコンのほうが安全です。

コピーできないのはなぜですか？

ブラウザーは、安全なページ（https://）または localhost でしかクリップボードへのコピーを許可しません。サイトを自分で運用している場合は HTTPS で配信してください。

これらのアイコンは商用プロジェクトで使えますか？

Lucide（ISC）、Feather（MIT）、Bootstrap Icons（MIT）は商用利用が可能です。プロジェクトにはライセンス表記を残してください。絵文字のデザインはフォントのベンダー（Microsoft、Apple、Google など）に帰属します。絵文字の文字をコピーするのは問題ありませんが、そのデザインを画像として使う前にベンダーの規約を確認してください。
