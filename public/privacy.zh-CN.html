隐私政策

最后更新：2026 年 11 月 11 日

Icon Library 没有用户账户，也不会索取个人数据。本页说明哪些内容保存在你的设备上、页面会与哪些外部服务通信，以及你有哪些选择。

负责人

Icon Library（iconlibrary.io）由 André M. Ferreira 运营，他对本网站以及本页所述的数据处理负责。

保存在你浏览器中的内容

本站会在你浏览器的本地存储中保存一些偏好设置。它们不会离开你的设备，也不会发送到我们的服务器：

  • Scratchpad 的文本（icon-library:scratchpad）；
  • 所选的大小、描边和颜色（icon-library:style）；
  • 浅色或深色主题（icon-library:theme）；
  • 如果你请过咖啡，你的支持者代码及其到期日期（icon-library:supporter）；
  • 编辑器打开期间你正在编辑的图标，以便页面重新加载后恢复；关闭编辑器即删除（icon-library:editor-draft）；
  • 你上次选择的图标集，下次访问时会打开它（icon-library:set）；
  • 所选的语言（icon-library:lang）。

如果你为了评价本站而使用 GitHub、Google 或 Microsoft 登录，已写好的评价内容只会保存在当前标签页（会话存储，icon-library:review-draft），回来后立即删除。登录还会设置一个只用于此目的的 Cookie（il_review_login，30 分钟），确保登录只在发起它的浏览器中有效。

你可以随时在浏览器设置中清除本站数据来删除它们。除上文所述用于评价登录的短期 Cookie 外，本站本身不设置 Cookie；统计 Cookie（Microsoft Clarity）和广告 Cookie 的说明见下文。

服务器日志

和所有网站一样，服务器在每次请求时都会收到技术数据——IP 地址、请求的页面、日期和时间以及浏览器类型。这些数据仅用于保障网站正常运行和安全，并在轮换日志中短期保存。

第三方服务

为了显示图标，你的浏览器会直接从以下服务下载图标，这些服务会在请求中收到你的 IP 地址和浏览器信息：

  • unpkg——全部四个图标集的数据；
  • lucide.dev——Lucide 图标的类别。

图标编辑器完全在你的浏览器中运行。对于 Lucide 和 Feather 图标，编辑器中的在 Lucide Studio 中打开按钮会打开 Lucide Studio——一个拥有独立隐私政策的网站——并把你正在编辑的图标发送给它。

请喝咖啡（Stripe）

“请我喝杯咖啡”的付款由 Stripe 处理，Stripe 依照其自身的隐私政策接收你的付款信息，这些信息不会经过本站。为了提供支持者权益，服务器只保存 Stripe 付款会话 ID、金额、付款日期、生成的支持者代码、其到期日期以及使用过的设备数量——不保存姓名、电子邮件或银行卡信息。续期时，服务器会保存新付款的会话 ID、金额和日期，并关联到同一个代码。这些记录会在兑现该权益以及开发者财务记录所需的期限内保存。

发布到 Iconlibrary

支持者可以把图标发布到社区图标集 Iconlibrary。每次提交时，服务器会保存图标（其 SVG）、名称、类别、你填写的可选署名、你的支持者代码，以及提交和审核日期。审核通过后，图标、名称和署名会公开，并以 MIT 许可证向所有人开放。如需删除你发布的图标，请通过下方的联系方式联系。

支持者的评价

支持者可以给 Icon Library 打 1 到 5 星并留下评论，审核后显示在“关于”页面。服务器会保存评分、评论、你填写的名字、你添加的照片（会被重新绘制成小图，去掉位置等元数据）、语言、你的支持者代码（从不公开）以及日期。如果你使用 GitHub、Google 或 Microsoft 登录，本站只读取你的名字、一个标识符和照片，用来填写表单并显示“已验证”标记；标识符只以不可逆的编码（哈希）保存，绝不保存服务商的访问令牌或你的电子邮件。没有你在表单中勾选的授权，不会公开任何内容。如需删除你的评价，请写信到下方的联系地址。

没有结果的搜索

当搜索在所选图标集中找不到任何图标时，页面会把搜索词、图标集和网站语言发送到服务器，服务器为该词的计数加一。不会发送其他任何内容：没有 IP 地址、没有标识符，也没有任何关于你的信息。看起来像个人信息的词（电子邮件、链接、长数字）会被丢弃。这些计数只用来了解大家在找却找不到哪些图标。

问题报告

当你通过页脚的表单报告问题时，服务器会保存你的描述、你填写的电子邮件地址（仅用于回复你），以及页面为帮助复现问题而一并发送的信息：页面地址、语言、浏览器（user agent）和窗口大小。你的 IP 地址不会随报告保存。只有网站负责人会阅读这些报告，不再需要时即会删除。如果你改为在 GitHub 上提交 issue，它将是公开的，并适用 GitHub 自己的隐私政策。

使用统计（Microsoft Clarity）

为了了解网站的使用方式以及访客遇到的障碍，本站页面使用 Microsoft Clarity。它会记录你与页面的交互——点击、滚动、鼠标移动和访问的页面——以及浏览器、设备和大致位置，并据此生成统计数据、热图和会话录像。表单中的文字、支持者代码、scratchpad 和编辑器中的 SVG 代码会在你的浏览器中被遮蔽，绝不会发送给 Clarity。

  • Clarity 会在本站设置 Cookie（_clck 最长保留一年，_clsk 保留一天），用于识别重复访问。来自欧洲经济区、英国和瑞士的访客在不使用这些 Cookie 的情况下被统计。
  • 数据由 Microsoft 处理，Microsoft 也可能按照 Microsoft 隐私声明所述使用这些数据，包括用于安全和广告。
  • 如不想参与，可以屏蔽本站的 Cookie，或使用能拦截跟踪器的浏览器扩展。

广告（Google AdSense）

本站可能展示由 Google AdSense 投放的广告。Google 及其合作伙伴使用 Cookie 和类似技术，根据你对本站及其他网站的访问来投放广告、限制同一广告的展示次数并衡量广告效果。

  • Google 使用广告 Cookie，使其及其合作伙伴能够根据你对本站和/或互联网上其他网站的访问投放广告。请参阅 Google 如何使用来自使用其服务的网站的信息。
  • 你可以在 Google 广告设置中停用个性化广告，或在 aboutads.info 停用部分第三方供应商的 Cookie。
  • 来自欧洲经济区、英国和瑞士的访问者在看到个性化广告之前，会通过 Google 的同意消息被征求同意。

你的权利

根据你所在的地区——例如依据巴西的 LGPD 或欧洲的 GDPR——你可能有权访问、更正或删除个人数据，并反对对其进行处理。由于 Icon Library 收集的个人数据很少，大多数请求都会涉及统计 Cookie 和广告 Cookie，你可以通过上面的链接和浏览器设置来控制它们。

联系方式

如对本政策有疑问或有关于你数据的请求，请发送邮件至 contact@iconlibrary.io 联系 André M. Ferreira。邮件由 Google Workspace 处理，仅在处理你的请求所需的期限内保存。也可以在项目的 GitHub 仓库中报告错误，issue 是公开的。

变更

如果本政策发生变更，新版本将发布在本页，并在顶部注明新的日期。
