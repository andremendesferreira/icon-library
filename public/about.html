About Icon Library

Icon Library is a free tool for picking icons for menus, buttons and interfaces. It gathers four popular sets in one searchable page, so you can compare styles side by side and copy exactly what you need — an SVG ready to paste into HTML, a React component, a PNG, or an emoji.

The icon sets

Lucide
Around 1,900 clean outline icons on a 24×24 grid, drawn with a 2px stroke. A community-maintained fork of Feather, and today the most complete of the outline sets. License: ISC.
Feather
The original minimalist outline set, with about 290 icons. Lucide started from it, so the two match in style and most names. License: MIT.
Bootstrap Icons
Over 2,000 icons from the Bootstrap team, many with outline and filled variants (the -fill names). They are drawn as filled shapes on a 16×16 grid. License: MIT.
Emoji (Unicode)
All standard emojis, grouped as in the Unicode standard. Unlike the others, emojis are text: how they look depends on the fonts installed on each device.

Step-by-step instructions for every feature — searching, styling, the scratchpad, the icon editor, .ile projects and keyboard shortcuts — are in the Guide.

Frequently asked questions

Why are some emojis flagged “without a design”?

The newest emojis are added to the Unicode standard before operating systems ship fonts that draw them. The page checks whether your system font can draw each emoji and flags the ones it cannot. Avoid those in a menu: your visitors would likely see an empty box. Tick Only those with a design on this machine to hide them.

Should I use emojis or vector icons in my interface?

Vector icons look the same everywhere, inherit the text color and scale cleanly. Emojis are quicker to add but change appearance between Windows, macOS, Android and iOS. For product interfaces, vector icons are usually the safer choice.

Why does copying fail?

Browsers only allow copying to the clipboard on secure pages (https://) or on localhost. If you run your own copy of the site, serve it over HTTPS.

Can I use these icons in commercial projects?

Lucide (ISC), Feather (MIT) and Bootstrap Icons (MIT) allow commercial use; keep their license notice in your project. Emoji designs belong to the font vendors (Microsoft, Apple, Google and others) — copying the emoji character is fine, but check the vendor's terms before using their artwork as images.
