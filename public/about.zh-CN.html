关于 Icon Library

Icon Library 是一个为菜单、按钮和界面挑选图标的免费工具。它把四个流行的图标集汇集在一个可搜索的页面上，方便你并排比较风格，复制真正需要的内容——可直接粘贴到 HTML 的 SVG、React 组件、PNG 或表情符号。

图标集

Lucide
约 1,900 个简洁的线框图标，基于 24×24 网格，描边宽度 2px。它是由社区维护的 Feather 分支，也是目前最完整的线框图标集。许可证：ISC。
Feather
最初的极简线框图标集，约 290 个图标。Lucide 由它发展而来，因此两者风格一致，大部分名称也相同。许可证：MIT。
Bootstrap Icons
来自 Bootstrap 团队的 2,000 多个图标，很多都有线框和填充两种版本（名称带 -fill）。它们以填充形状绘制在 16×16 网格上。许可证：MIT。
Emoji (Unicode)
所有标准表情符号，按 Unicode 标准分组。与其他图标不同，表情符号是文字：外观取决于每台设备上安装的字体。

各项功能的分步说明——搜索、样式、Scratchpad、图标编辑器、.ile 项目和键盘快捷键——请参阅指南。

常见问题

为什么有些新表情符号没有显示？

最新的表情符号先被加入 Unicode 标准，之后操作系统才会提供能显示它们的字体。页面会检查你设备上的字体能否显示每个表情符号，并隐藏不能显示的：放在菜单里，访问者很可能只会看到一个空方框。换一部手机、平板或电脑，列表可能会不同。

界面中应该使用表情符号还是矢量图标？

矢量图标在任何地方看起来都一样，会继承文字颜色，缩放也不失真。表情符号添加起来更快，但在 Windows、macOS、Android 和 iOS 上外观不同。对于产品界面，矢量图标通常是更稳妥的选择。

为什么复制会失败？

浏览器只允许在安全页面（https://）或 localhost 上复制到剪贴板。如果你自行部署了本站，请通过 HTTPS 提供服务。

这些图标可以用于商业项目吗？

Lucide（ISC）、Feather（MIT）和 Bootstrap Icons（MIT）允许商业使用；请在项目中保留它们的许可证声明。表情符号的设计归字体厂商（Microsoft、Apple、Google 等）所有——复制表情字符没有问题，但若要把它们的图形作为图片使用，请先查看厂商的条款。
