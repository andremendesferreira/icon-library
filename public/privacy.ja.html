プライバシーポリシー

最終更新日：2026 年 11 月 9 日

Icon Library にはユーザーアカウントがなく、個人データを求めることもありません。このページでは、端末に保存される内容、ページが通信する外部サービス、そしてあなたが選べることを説明します。

責任者

Icon Library（iconlibrary.io）は André M. Ferreira が運営しており、本サイトおよびこのページに記載するデータの取り扱いについて責任を負います。

ブラウザーに保存される内容

本サイトはいくつかの設定をブラウザーのローカルストレージに保存します。これらが端末の外に出ることはなく、当サーバーに送られることもありません：

  • Scratchpad のテキスト（icon-library:scratchpad）；
  • 選んだサイズ・線の太さ・色（icon-library:style）；
  • ライトまたはダークのテーマ（icon-library:theme）；
  • コーヒーをおごってくれた場合、サポーターコードとその終了日（icon-library:supporter）；
  • エディターを開いている間、編集中のアイコン。ページが再読み込みされても復元できるようにするためで、エディターを閉じると削除されます（icon-library:editor-draft）。
  • 最後に選んだアイコンセット。次回の訪問時に開きます（icon-library:set）。
  • 選んだ言語（icon-library:lang）。

ブラウザーの設定で本サイトのデータを消去すれば、いつでも削除できます。本サイト自体は Cookie を設定しません。統計用 Cookie（Microsoft Clarity）と広告 Cookie については後述します。

サーバーのログ

ほかのウェブサイトと同様に、サーバーはリクエストごとに技術的なデータ——IP アドレス、要求されたページ、日時、ブラウザーの種類——を受け取ります。これらはサイトの運用と安全のためだけに使われ、ローテーションするログに短期間だけ保存されます。

外部サービス

アイコンを表示するため、ブラウザーは次のサービスから直接アイコンをダウンロードします。これらのサービスはリクエストの一部として IP アドレスとブラウザーの情報を受け取ります：

  • unpkg——4 つすべてのセットのアイコンデータ；
  • lucide.dev——Lucide アイコンのカテゴリ。

アイコンエディターはすべてブラウザー内で動作します。Lucide と Feather のアイコンで表示されるLucide Studio で開くボタンは、独自のプライバシーポリシーを持つ独立したサイト Lucide Studio を開き、編集中のアイコンをそこへ送ります。

コーヒーをおごる（Stripe）

「コーヒーをおごる」の支払いは Stripe が処理し、支払い情報は Stripe 自身のプライバシーポリシーに従って Stripe が受け取ります。このサイトを経由することはありません。サポーター特典を提供するため、サーバーには Stripe の決済セッション ID、金額、支払日、発行したサポーターコード、その終了日、使用された端末の数だけを保存します。名前、メールアドレス、カード情報は保存しません。更新した場合は、新しい支払いのセッション ID、金額、日付を同じコードに結びつけて保存します。これらの記録は、特典の提供と開発者の会計記録に必要な期間だけ保存されます。

Iconlibrary への公開

サポーターはコミュニティのアイコンセット Iconlibrary にアイコンを公開できます。送信ごとに、サーバーはアイコン（SVG）、名前、カテゴリ、任意で入力したクレジット、サポーターコード、送信日と審査日を保存します。承認されると、アイコン、名前、クレジットは公開され、MIT ライセンスで誰でも利用できるようになります。公開したアイコンを削除したい場合は、下記の連絡先までご連絡ください。

不具合の報告

フッターのフォームから不具合を報告すると、サーバーはメッセージ、入力された場合はメールアドレス（返信のためだけに使用）、そして問題の再現に役立つようページが一緒に送る情報（ページのアドレス、言語、ブラウザー（ユーザーエージェント）、ウィンドウサイズ）を保存します。IP アドレスは報告と一緒に保存しません。報告を読むのはサイトの運営者だけで、不要になったら削除します。代わりに GitHub で issue を作成した場合、それは公開され、GitHub のプライバシーポリシーに従います。

利用状況の統計（Microsoft Clarity）

サイトがどのように使われ、訪問者が何につまずいているかを知るために、本サイトのページでは Microsoft Clarity を使用しています。クリック、スクロール、マウスの動き、閲覧したページなどページの操作を、ブラウザー、デバイス、おおよその位置とともに記録し、統計、ヒートマップ、セッションの録画にします。フォームの文字、サポーターコード、scratchpad、エディターの SVG コードはブラウザー内でマスクされ、Clarity に送られることはありません。

  • Clarity は再訪問を識別するために本サイトの Cookie（_clck は最長 1 年、_clsk は 1 日）を設定します。欧州経済領域、英国、スイスからの訪問者は、これらの Cookie を使わずに計測されます。
  • データは Microsoft によって処理され、Microsoft プライバシー ステートメントに記載されているとおり、セキュリティや広告などにも使われることがあります。
  • 参加したくない場合は、本サイトの Cookie をブロックするか、トラッカーをブロックするブラウザー拡張機能を使ってください。

広告（Google AdSense）

本サイトでは Google AdSense による広告を表示することがあります。Google とそのパートナーは、Cookie や同様の技術を使って、本サイトやほかのサイトへの訪問に基づいた広告を配信し、同じ広告の表示回数を制限し、広告の効果を測定します。

  • Google は広告 Cookie を使用することで、Google とそのパートナーが本サイトやインターネット上のほかのサイトへの訪問に基づいて広告を配信できるようにしています。詳しくは Google のサービスを使用するサイトからの情報を Google が使用する方法をご覧ください。
  • パーソナライズド広告は Google の広告設定で無効にでき、一部の第三者ベンダーの Cookie は aboutads.info で無効にできます。
  • 欧州経済領域、英国、スイスからの訪問者には、パーソナライズド広告を表示する前に Google の同意メッセージで同意を求めます。

あなたの権利

お住まいの地域によっては——たとえばブラジルの LGPD や欧州の GDPR に基づき——個人データへのアクセス、訂正、削除を求める権利や、その処理に異議を唱える権利がある場合があります。Icon Library が収集する個人データはわずかなため、ほとんどの要望は統計用 Cookie と広告 Cookie に関するものになります。これは上記のリンクとブラウザーの設定で管理できます。
