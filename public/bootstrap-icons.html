Bootstrap Icons

Bootstrap Icons is an open-source set of over 2,000 icons from the Bootstrap team. You don't need the Bootstrap framework to use it: the icons are plain SVG files that work in any project.

Outline and filled versions

This is the main difference from Lucide and Feather. Many icons come in pairs, such as star and star-fill, which suits states like "not favorited" and "favorited". The shapes are filled paths on a 16×16 grid, rather than lines, so they stay crisp at small sizes.

One consequence: since there is no stroke to adjust, stroke-width doesn't make these icons lighter. Color works through fill, using currentColor.

License

Bootstrap Icons uses the MIT license: you can use and modify the icons in personal and commercial projects. Keep the license notice when you redistribute the package.

SVG or icon font?

The set offers both. The font is quick to set up:

npm install bootstrap-icons

    <link rel="stylesheet" href="bootstrap-icons/font/bootstrap-icons.min.css">
    <i class="bi bi-search" aria-hidden="true"></i>

The trade-off is that the font carries every icon, even if you use ten of them. If you only need a few, pasting the SVG loads nothing extra. It also avoids the moment when a font hasn't loaded yet and the icon is missing.

When to choose it

  • You already use Bootstrap: the look matches the components.
  • You need many subjects: the set has a wide range, including brands.
  • You need filled states: the pairs are already drawn.

For a light, line-based look, Lucide tends to fit better. Avoid mixing the two on the same screen, because filled 16×16 shapes and 24×24 lines have different visual weights.

Brand icons

The set includes logos of companies and products. The MIT license covers the files, but it doesn't give you rights over the trademarks they show, so follow each brand's guidelines.
