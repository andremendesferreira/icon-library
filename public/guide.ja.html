使い方

  1. 選択ボタンでセットを選びます。ページは Lucide か、前回選んだセットで開き、各セットはページを開いている間キャッシュされます。
  2. すべてのカテゴリ（複数選択可）と検索欄で絞り込みます。/ キーで検索欄に移動できます。検索はアイコンの名前とキーワードが対象なので、「delete」でゴミ箱も見つかり、一致度の高いものが先に並びます。名前とキーワードは英語です。何も見つからないときは、検索やカテゴリのクリア、ほかのセットで同じ語を探すボタンが表示されます。
  3. サイズ・線の太さ・色でスタイルを設定します。コピー、ダウンロード、Scratchpad への送信すべてに適用され、プレビューも線と色に合わせて変わります。線があるのは Lucide と Feather だけで、絵文字は元の色のままです。装飾は aria-hidden="true" を追加し、横に文字があるアイコンをスクリーンリーダーが読み飛ばすようにします。
  4. アイコンをクリックすると SVG（または絵文字の文字）をコピーします。右クリックは別の形式をコピーします：ベクターのセットではアイコン名、絵文字では SVG で包んだ絵文字です。
  5. 各カードのボタン：
    • + アイコンを Scratchpad に追加；
    • ⋯ ダウンロード（SVG、選んだサイズの PNG）とReact・Vue・Svelte コンポーネント、data URI、文字の色になる CSS クラスとしてのコピー；
    • 鉛筆（すべてのベクターセット）でアイコンエディターを開きます。

アイコンエディター

カードの鉛筆を押すと、アイコンがグリッド上に開き、すぐに編集できます。アイコンには選んだサイズ・線・色が反映されています。

  • 形を変える：リストまたはグリッドで図形を選び、点をドラッグします。曲線には破線でつながった制御点が表示され、曲線上の点を動かすと制御点も一緒に動きます。
  • 移動：図形をドラッグするか、矢印キーやボタンを使います。点はグリッドにスナップします（1、½、¼ 単位、またはオフ）。
  • 変形：90°・45° 回転、反転、拡大・縮小——選んだ図形に、何も選んでいなければアイコン全体に適用されます。
  • 追加と削除：線・円・四角形・曲線を追加できます。図形を非表示にしてそれがない状態を確認したり、削除したりできます。
  • アイコンを組み合わせる：アイコンを重ねるで Lucide、Feather、Bootstrap を検索し、別のアイコンを今のアイコンの上に重ねます。同じグリッドに合わせて調整され、元のスタイルも保たれます——Bootstrap の塗りつぶしの星を Lucide の線画のハートの中に置くこともできます。各アイコンにはリストに見出しがあり、クリックするとアイコン全体を選択して移動・回転・拡大縮小できます。
  • 複数の図形を選択：空白をドラッグすると、四角形に触れたものがすべて選択されます。Shift を押すとどこからでもドラッグして選択に追加でき、Shift+クリックで図形を追加・除外できます。Ctrl+A ですべて選択、Esc で解除します。まとめて移動、回転、拡大縮小、色の変更、並べ替え、コピー、削除ができます。グループ化（Ctrl+G）するとまとまり、クリックでグループ全体、ダブルクリックで図形を1つ選択します。重ねたアイコンも同じように動作し、グループ解除（Ctrl+Shift+G）で図形を解放します。
  • 結合、分割、重ね順：結合（Ctrl+J）は開いた線2本を、最も近い端でつないで1本にします。開いた線を1本選択すると図形を閉じ、点も選択すると最も近い端をその点につなぎます。分割はカーソルを照準に変えます。線を切る位置をクリックし、Esc でキャンセルします。「変形」の4つの重ね順ボタンで、図形を1段または端まで前後に移動できます。? ボタンまたは ? キーで、すべてのコマンドをキーとマウス操作とともに表示します。
  • ズーム：マウスホイール、図の上にある虫めがねボタン、または + と − キーでポインターを中心に拡大縮小できます。スマートフォンでは 2 本の指でピンチします。Space を押しながらドラッグ（または中ボタンでドラッグ）すると表示を移動でき、パーセント表示をクリックするか 0 を押すと図全体に戻ります。
  • 手でサイズ変更と回転：選択したものにはハンドル付きの枠が表示されます。角をドラッグすると縦横比を保ったままグリッド単位でサイズが変わり、枠の上の点をドラッグすると 15° ずつ回転します。Shift を押すと自由な値になります。正確な数値は選択中パネルの X、Y、幅、高に入力します。
  • 整列、スナップ、複製：整列ボタンは複数の図形を互いに揃え（図形 1 つ、グループ、アイコン全体ならアイコンの領域の中央に置き）、3 つ以上を等間隔に並べます。ドラッグ中は点や図形がほかの図形やアイコンの中心に吸着し、ピンクのガイド線が出ます。Alt を押すと自由にドラッグできます。複製（Ctrl+D）は選択したものの横にコピーを作り、Shift+矢印キーはグリッド 10 マス分動かします。
  • ペンで描く：既成の図形の隣にあるペンボタンで、自分の線を描けます。クリックで点を追加し、点を置くときにドラッグすると曲線になります。最初の点をクリックすると図形が閉じます。開いた線は Enter か完了で終わり、Esc で取り消します。
  • 線の端、角、最後の確認：端（丸、平ら、四角）と角（丸、とがり、面取り）で線の仕上がりが変わります。元の図を押し続けると開いたときのアイコンが見え、明るい背景と暗い背景のプレビューを見比べられます。コードの上の最適化は図を変えない部分を取り除きます。
  • 失わない仕組み：削除、分割、結合、最適化のあと、下に出るメッセージに元に戻すボタンがあります。編集中の内容はブラウザーにも保存されます。ページが再読み込みされたりタブが閉じたりしても、次にエディターを開いたときに復元を提案します。自分でエディターを閉じると破棄されます。リストでは図形をドラッグして同じアイコンやグループ内の順序を変えられ、✎ でグループ名を変更できます。図にフォーカスがあるとき、Tab で次の図形を選び、スクリーンリーダーがどれかを読み上げます。
  • スマートフォンでは：図は常に表示され、ツールはその下のタブ（図形、編集、変形、要素、書き出し）にあります。図の近くのバーには、元に戻す、やり直す、削除、複数があり、複数ではタップごとに図形を追加・除外します。図形を0.5秒押さえて追加・除外することもできます。最初のタップは図形を選択するだけなので、誤って動かすことはありません。選択してからドラッグしてください。
  • 図形の塗りつぶし：閉じた図形を選択して塗りつぶしを使うと内側が線の色で塗られ、同じボタンで解除できます。開いた線は先に結合で閉じてください。
  • 順序を確認：要素リストの上にあるレイヤーを表示は、図形ごとに色を付け、最前面と最背面を示します。グループは1つのまとまりとして1色で表示されます。表示が変わるだけで、アイコンは変わりません。
  • 色：選択中パネルで、図形ごと・アイコンごとに色と線の太さを設定できます。文字色を押すと周囲の文字色を引き継ぐ状態に戻ります。独自の色を持つ図形は、どこに貼り付けてもその色を保ちます。
  • 保存して後で続ける：.ile を保存でプロジェクトを .ile ファイルとしてダウンロードします。素の SVG では失われる情報——各図形がどのアイコンから来たか、非表示の図形、名前——を保存する小さなテキストファイルです。エディターやメインページの検索欄の横にある.ile を開くで再び開くか、ファイルをエディターにドロップします。編集中にファイルを開いても元に戻せます。
  • コード：グリッドの横の SVG コードはすべての変更に追従し、直接入力することもできます。プレビューでは 16、24、32、48 ピクセルでの見え方を確認できます。
  • 元に戻すとやり直す（Ctrl+Z、Ctrl+Y）を使い、編集したアイコンをコピー、ダウンロード、または Scratchpad に送れます。Lucide と Feather のアイコンは、より高度なツールを備えた独立のオンラインエディター Lucide Studio でも開けます。

Scratchpad

右端の Scratchpad タブを押すと引き出しが開き、閲覧しながらアイコンを集められます。各アイコンは名前入りの HTML コメントと、その下の SVG として追加されるので、そのままプロジェクトに貼り付けられます。自由に書き込むこともできます。すべてコピーで内容をコピーし、クリアで空にします。テキストはブラウザーに保存されるので、次回もそのまま残っています。テキストの上には、含まれているアイコンがグリッドで表示されます。クリックするとエディターで開き、Scratchpad に保存で編集したものを同じ場所に戻します。SVG を追加ではパソコンの SVG ファイルを追加でき（グリッドへのドロップも可）、エディターに貼り付けたコードと同じように安全処理されます。

AI アシスタント向け

AI アシスタントはアイコンを作り、ここエディターでそのアイコンを開くリンクとして渡すことができます。アイコンはリンクそのもの（# の後ろ）に含まれているため、当サーバーに送られることはありません。エディターのリンクを共有で、自分のプロジェクトにも同じ種類のリンクを作れます。AI 向けの説明：llms.txt。

検索を共有する

アドレスバーは表示中の内容に合わせて変わります——たとえば ?set=lucide&q=arrow。アドレスをコピーすれば、検索を共有したりブックマークしたりできます。

テーマ、言語、設定

ページはシステムのライト／ダークテーマに従い、ヘッダーのボタンで切り替えられます。言語はブラウザーから自動判定され、隣の選択欄で変更できます。これらの選択、サイズ・線の太さ・色の設定、Scratchpad のテキストはブラウザーに保存され、次回もそのまま残ります。

コーヒーをおごる

Icon Library は無料です。役に立ったら、コーヒーをおごるボタン（Stripe で安全に支払い）でサーバーやドメイン、運営に使うツールの費用を支援できます。お礼として、支払いから 30 日間 Iconlibrary で自分のアイコンを公開・編集でき、サイトに広告が表示される場合も表示されません。

☕ コーヒーをおごる

支払い後にサポーターコードが届きます。別の端末でもこれらの特典を使うには（最大 3 台）、その端末で同じボタンを開いてコードを入力してください。このボタンは支払いが利用できるときだけ表示されます。

Iconlibrary に公開する

Iconlibrary はコミュニティのアイコンセットです。サポーターがエディターで描いたアイコンを審査し、みんなで共有します。ほかのセットと同じようにセット一覧に表示されます。

  1. エディターでアイコンを開き、描いたり調整したりします。
  2. Iconlibrary に公開を押し、名前を付け、カテゴリを 3 個まで選び、必要ならクレジット（名前やサイト）を入力します。
  3. コーヒーをおごった端末では、サポーターコードが自動で入力されます。別の端末では入力してください。
  4. 自分で作成した（または共有する権利がある）アイコンで、MIT ライセンスで公開することを確認して送信します。審査後に Iconlibrary に表示されます。

公開できるのは基本的な図形——線、円、楕円、四角形、ポリライン、多角形、パス（path）だけです。ブランドのロゴや、ほかのアイコンのコピーは受け付けません。
